# matchly.-App-de-Cadastro-de-Curriculum
Plataforma SaaS completa de inteligência de empregabilidade que conecta candidatos às vagas mais compatíveis com seus perfis profissionais. Além disso, cria versões personalizadas e estratégicas de currículos, totalmente otimizadas para aprovação nos filtros de sistemas ATS (Applicant Tracking Systems), acelerando a recolocação no mercado.
